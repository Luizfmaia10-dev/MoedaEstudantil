# Distribuição de Moedas e Resgate de Vantagens Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar RF-004, RF-005, RF-007, RF-009 e RF-010 com movimentações atômicas, e-mails SMTP e telas integradas à interface existente.

**Architecture:** Dois serviços transacionais coordenam distribuição e resgate usando os repositórios atuais e bloqueio pessimista das contas. Um serviço de notificação encapsula `JavaMailSender`; controladores REST expõem dados de tela e comandos. Duas páginas estáticas consomem as APIs e usam um utilitário GSAP compartilhado para os modais.

**Tech Stack:** Java 21, Spring Boot 4.1, Spring Data JPA, Spring Mail, JUnit 5, Mockito, HTML/CSS/JavaScript e GSAP 3.

**Spec:** `docs/superpowers/specs/2026-10-19-rf-004-005-007-009-010-design.md`

## Global Constraints

- Reutilizar a identidade visual de `frontend/css/styles.css`.
- Manter `frontend/` e `demo (2)/demo/src/main/resources/static/` sincronizados.
- Não versionar credenciais SMTP.
- Não alterar autenticação nem substituir IDs de demonstração por sessão.
- Não adicionar fila, retentativa persistente ou refatoração fora do escopo.
