# Requisitos RF-001 a RF-003 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar autenticação dos três perfis, instituição obrigatória no cadastro do aluno e crédito semestral idempotente para professores.

**Architecture:** Serviços Spring concentram autenticação, cadastro e crédito; controllers ficam finos. O frontend usa módulos próprios e não altera o menu em reformulação.

**Tech Stack:** Java 21, Spring Boot 4, JPA, BCrypt, JUnit 5, Mockito, JavaScript e Node `node:test`.

**Spec:** `docs/superpowers/specs/2026-10-20-requisitos-001-003-design.md`

## Global Constraints

- Não modificar `frontend/dev-menu.html` nem arquivos com alterações concorrentes.
- Preservar endpoints existentes.
- Usar janeiro-junho como semestre 1 e julho-dezembro como semestre 2.
- Sincronizar `frontend/` pelo script existente.
